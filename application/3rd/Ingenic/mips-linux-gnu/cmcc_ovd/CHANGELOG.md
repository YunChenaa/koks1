2022/8/13:
需求背景：
当前哭声告警的音乐安抚及警戒功能的语音播放等功能机制是安防设备从平台下载音频文件然后进行本地播放实现。目前平台部署音频文件统一为8K采样率，但对于部分设备（16K采样率）而言，设备端需要有个重采样过程。为了避免重采样过程，本需求中平台同时配置8K及16K采样率文件，根据设备上报对应的能力集音频采样率字段，来下发特定的音频文件。
新增能力集字段
audiosamplerate: 设备音频采样率<枚举整型，0（默认值）：代表8K， 1：代表16K，后续方便扩充>

2.0.0
================================
这是首个正式发布的ovd sdk版本，本地视音频设备可以通过SDK提供的统一接入能力接入到开放云平台，提供相应的服务及设置。
ovd sdk 通过websocket协议与云平台进行信令交互，支持二维码识别，声波配网，图片上传，p2p,stream rtmp ,stream cseg, 告警，截图，设备控制等功能。

相关接入协议介绍：
    https://open-dev-protocol.readthedocs.io/en/latest/dap.html#

当前编译服务器版本为：
	centos 7.x   x86 gcc版本为4.8.5    C++库为libstdc++.so.6.0.19
建议厂商x86下二次编译时，gcc和c++库不低于以上版本
